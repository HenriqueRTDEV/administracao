# Portfólio de Administração

Site estático desenvolvido com HTML, CSS e JavaScript puro. Não utiliza banco de dados, servidor ou framework.

## Como executar
1. Extraia os arquivos.
2. Abra `index.html` no navegador.

## Arquivos
- `index.html`: estrutura e conteúdo do portfólio.
- `style.css`: identidade visual e responsividade.
- `script.js`: menu mobile e ano automático do rodapé.

## Antes de publicar
- Substitua nome, formação, cursos, experiências, e-mail e LinkedIn.
- Atualize os três projetos demonstrativos com trabalhos reais ou acadêmicos.
- Não apresente metas ou valores ilustrativos como resultados alcançados.
- Revise o conteúdo e atualize a data de revisão a cada seis meses.
- Em projetos empresariais, remova informações confidenciais e obtenha autorização quando necessário.
